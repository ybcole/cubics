## Immediate runtime hardening (defense-in-depth, not authorization)

Changed `socket-server.cjs` and `src/lib/security/realtime-room-policy.cjs` to restrict existing `presence:snapshot`, `presence:update`, `room:update`, `token:state`, `sb:offer-to`, `sb:ice`, `voice:signal`, hosted tab input and shared browser host references to the socket's joined room. This removes several cross-room relay paths **among sockets that genuinely are in different joined rooms**. It **does not** stop a malicious client from asking to join a room it is not authorized to access. That defect must be fixed under M03/M15 before GA.

## Critical gates still open

1. Reject unauthenticated and forged-member room joins using Clerk + DB authority (T01; M03).
2. Protect native sandbox and user-authorized media capture (T04/T05; M04). T06's unused legacy URL probe has been retired in M01 (HTTP 410); full outbound-policy review remains M04.
3. Eliminate shipped backend secrets (T08; M02).
4. Scan and remediate high/critical dependency findings; make audit failure a hard CI gate (T15).
5. Run real negative API/socket integration for cross-user mutation, malicious token, credential/cookie isolation (M03/M05).
6. Establish branch protection requiring green security workflow as a merge gate (repo admin configuration may be needed).
