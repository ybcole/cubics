## Open security risks

Legacy membership by short room-code prefix needs invite/rate protections. Room roles and widget ownership must also be checked on LiveKit issuance and every Remote Control operation, not only Socket.IO room membership. The Electron app still has a sandbox and browser-permission policy debt under M04. Neither M03 exit criterion nor milestone sign-off is satisfied by fixture-backed tests alone.

**M03.E1, M03.E2 and SIGNOFF:** pending authentic staging, multi-account and revocation E2E. No `[COMPLETED]` marker.

## Realtime provider migration

The owner approved ADR-0008's Supabase private Realtime target with Clerk JWT authorization. Current Socket.IO is a temporary compatibility implementation; RLS and event/role/media parity have not been verified on live Supabase. Do not claim completed M03 solely from API and fixture tests.
