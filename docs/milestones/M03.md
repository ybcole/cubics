## Open security risks

Legacy membership by short room-code prefix still needs invite/rate protections. LiveKit role/widget grants and bounded Shared input are implemented; exclusive controller fencing, cross-instance revocation and configured-provider acceptance remain. M04 sandbox/IPC/profile foundations and native fixture coverage now exist, while complete platform permission/security acceptance remains open. Neither M03 exit criterion nor sign-off is satisfied by fixture-backed tests alone.

**M03.E1, M03.E2 and SIGNOFF:** pending authentic staging, multi-account and revocation E2E. No `[COMPLETED]` marker.

## Realtime provider migration

The owner approved ADR-0008's Supabase private Realtime target with Clerk JWT authorization. Current Socket.IO is a temporary compatibility implementation; RLS and event/role/media parity have not been verified on live Supabase. Do not claim completed M03 solely from API and fixture tests.
